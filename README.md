# Chisel

A SwiftUI app for macOS, iPhone and iPad that losslessly recompresses files with [chisel](https://github.com/Snesnopic/chisel).

## Install

On macOS 14 or later, with [Homebrew](https://brew.sh):

```sh
brew install --cask snesnopic/tools/chisel
```

This also installs `chsl`, chisel's command-line tool. The app doesn't need it, since the engine is built into the app.
